| 자동 결제 실패 | 결제 | 주문, 알림 | `paymentDeadline` 설정 + Redis key TTL 등록 / 낙찰자·판매자 알림 |
| 결제 성공 | 결제 | 주문, 정산, 알림 | 주문 상태 변경 + 스냅샷 생성 / 정산 엔티티 생성 / 낙찰자·판매자 알림 |
| 정산 생성 완료 | 정산 | 알림 | 판매자에게 정산 예정 금액 알림 |
| 정산 완료 | 정산 | 알림 | 판매자에게 정산 완료 알림 |

## 소비 도메인별 상세

### 경매 (Auction Consumer)

| 소비 이벤트 | 처리 내용 |
|-----------|---------|
| 관리자 경매 취소 | Redis key 삭제 |
| 경매 종료 | Redis shadow key 삭제, 경매 스냅샷 저장 |

### 주문 (Order Consumer)

| 소비 이벤트 | 처리 내용 |
|-----------|---------|
| 경매 종료 | 주문 생성 |
| 직접 결제 실패 | 주문 상태 → `DIRECT_PAYMENT_FAILED` |
| 자동 결제 실패 | `paymentDeadline` 설정, Redis key TTL 등록 |
| 결제 성공 | 주문 상태 변경, 주문 스냅샷 생성 |

### 결제 (Payment Consumer)

| 소비 이벤트 | 처리 내용 |
|-----------|---------|
| 주문 생성 | 결제 엔티티 생성 |

### 정산 (Settlement Consumer)

| 소비 이벤트 | 처리 내용 |
|-----------|---------|
| 결제 성공 | 정산 엔티티 생성 |

### 알림 (Notification Consumer)

| 소비 이벤트 | 수신 대상 |
|-----------|---------|
| 경매 검수 통과 | 판매자 |
| 경매 검수 실패 | 판매자 |
| 경매 활성화 | 판매자 |
| 관리자 경매 취소 | 판매자, 입찰자 전원 |
| 경매 종료 | 판매자, 낙찰자 |
| Outbid | 직전 최고 입찰자 |
| 직접 결제 실패 | 낙찰자, 판매자 |
| 자동 결제 실패 | 낙찰자, 판매자 |
| 결제 성공 | 낙찰자, 판매자 |
| 정산 생성 완료 | 판매자 |
| 정산 완료 | 판매자 |
