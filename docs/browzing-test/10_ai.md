# 10. AI 기능 테스트 시나리오

## 사전 조건
- AI 서비스 연결 확인 (Gemini 1.5 Flash API)
- 승인된 카드(cardId) 존재

---

## TC-AI-001: 카드 AI 분석 조회 (캐시)

**우선순위**: 중  
**관련 API**: `GET /api/ai/cards/{cardId}/analysis`  
**인증 필요**: 있음

### 요청
```
GET /api/ai/cards/{CARD_ID}/analysis
Authorization: Bearer {ACCESS_TOKEN_A}
```

### 예상 응답
```json
{
  "cardId": 1,
  "analysis": "이 카드는 PSA 10 등급으로 ...",
  "grade": "PSA_10",
  "rarity": "RARE",
  "condition": "MINT"
}
```

### 확인 항목
- [ ] 200 응답
- [ ] 분석 결과 텍스트 포함
- [ ] 캐시된 결과 반환 여부 확인 (두 번 호출 시 동일 응답, 빠른 응답 속도)
- [ ] 분석 결과가 없는 카드 → 분석 자동 시작 또는 404

**관련 API**: `POST /api/ai/cards/{cardId}/analysis`  
**인증 필요**: 있음

### 요청
```
POST /api/ai/cards/{CARD_ID}/analysis
Authorization: Bearer {ACCESS_TOKEN_A}
```

### 확인 항목
- [ ] 200 응답
- [ ] 새로운 분석 결과 반환 (기존 캐시 무효화)

- [ ] Circuit Breaker 동작 확인 (AI API 불가 시 fallback 응답)

## TC-AI-003: AI 어시스턴트 채팅

**우선순위**: 중  
**관련 API**: `POST /api/ai/assistant/chat`  
**인증 필요**: 있음

### 요청
```json
POST /api/ai/assistant/chat
Authorization: Bearer {ACCESS_TOKEN_A}

{
  "sessionId": "session-001",
  "message": "피카츄 PSA 10 카드의 시장 가치는 얼마나 되나요?"
}
```

### 예상 응답
```json
{
  "sessionId": "session-001",
  "response": "피카츄 PSA 10 카드의 경우 ...",
  "tokenUsage": {
    "inputTokens": 150,
    "outputTokens": 300
  }
}
```

### 확인 항목
- [ ] 200 응답
- [ ] 자연어 응답 포함
- [ ] RAG 컨텍스트 활용 여부 (카드 관련 구체적 정보 포함)
- [ ] sessionId 유지 시 이전 대화 문맥 유지 확인

## TC-AI-004: AI 어시스턴트 스트리밍

**우선순위**: 중  
**관련 API**: `GET /api/ai/assistant/stream`  
**인증 필요**: 있음  
**방식**: Server-Sent Events (SSE)

### 요청
```
GET /api/ai/assistant/stream?message=피카츄 카드 추천해줘&sessionId=session-001
Authorization: Bearer {ACCESS_TOKEN_A}
Accept: text/event-stream
```

### 확인 항목
- [ ] `text/event-stream` Content-Type
- [ ] 실시간 스트리밍으로 응답이 조금씩 도착하는지 확인
- [ ] 스트림 완료 신호 수신

---

## TC-AI-005: 대화 세션 연속성

**우선순위**: 중

### 시나리오
1. 첫 번째 메시지: `"피카츄 카드에 대해 알려줘"` (sessionId: "test-session")
2. 두 번째 메시지: `"그 카드의 가격은?"` (동일 sessionId: "test-session")

### 확인 항목
- [ ] 두 번째 질문에서 "그 카드"가 피카츄를 지칭하여 올바르게 응답하는지 확인
- [ ] 다른 sessionId로 두 번째 질문 시 컨텍스트 없이 응답 (세션 독립성)

---

## TC-AI-006: AI API 장애 상황 Circuit Breaker

**우선순위**: 중

### 확인 항목
